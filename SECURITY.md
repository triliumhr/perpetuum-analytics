# Security policy

## Supported versions

| Version                               | Support                                                  |
| ------------------------------------- | -------------------------------------------------------- |
| 3.x, `@triliumhr/perpetuum-analytics` | fixes and new features, on the two newest Angular majors |
| 2.x, `perpetuum-analytics`            | security fixes only, until 30 April 2027                 |
| older than 2.0                        | none                                                     |

2.x gets no new features and no new Angular versions. A security fix for it comes as a 2.x patch release under `perpetuum-analytics`. From 1 May 2027 it gets no more releases; to keep receiving fixes, move to 3.x with the [migration guide](docs/en/06-migrating-from-2.md).

## Reporting a vulnerability

Please report it privately through [GitHub's vulnerability reporting](https://github.com/triliumhr/perpetuum-analytics/security/advisories/new), not in a public issue. Describe what you found, the affected version and, if you can, the steps that show it.

You get an answer within five working days. Once the fix is released, the advisory is published and names you, if you would like that.
